# Dash Launcher

Dash Launcher es un launcher para Android diseñado para facilitar la instalación y administración de distintas versiones de Geometry Dash desde una sola aplicación.

Permite explorar un catálogo de versiones, consultar la información de cada una y seleccionar la que se desea instalar. Su objetivo es automatizar la descarga y la instalación para que no sea necesario buscar ni importar manualmente los archivos del juego.

Inspirado en Prism Launcher, Dash Launcher busca ofrecer una forma sencilla de organizar y cambiar entre versiones de Geometry Dash, manteniendo cada instalación independiente para evitar que una versión sobrescriba a otra.
